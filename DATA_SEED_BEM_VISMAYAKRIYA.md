- `programs`: seluruh program kerja di atas

## 15. INSTRUKSI UNTUK ANTIGRAVITY

Gunakan data di dokumen ini sebagai data awal aplikasi. Jangan membuat nama pengurus, nama unit, atau nama program kerja tambahan jika tidak diperlukan.

Jangan memasukkan NIM, alamat, tanggal lahir, atau nomor kontak ke UI mockup kecuali memang diperlukan oleh fitur profil. Untuk data demo utama, cukup gunakan nama, role, unit, dan program kerja.

Untuk dashboard pimpinan, gunakan seluruh unit sebagai sumber data monitoring. Untuk dashboard Kepala Dinas/Sekretaris Dinas, tampilkan data unitnya sendiri. Untuk Staff, tampilkan data yang relevan dengan dirinya.

Program kerja tidak perlu memiliki field deskripsi pada seed data ini. Gunakan field seperti nama, unit, PIC, status, progress, deadline, dan anggaran jika diperlukan oleh aplikasi.

Status dan progress boleh menggunakan data dummy untuk kebutuhan prototype. Tandai data tersebut sebagai mock data dan jangan menganggap progress tersebut sebagai data real organisasi.
