# Dinas Internal - BEM KM FTI UNAND (Kabinet Vismayakriya)

Sistem Informasi Manajemen Dinas Internal Badan Eksekutif Mahasiswa Keluarga Mahasiswa Fakultas Teknologi Informasi (BEM KM FTI) Universitas Andalas - Kabinet Vismayakriya 2025/2026.

Repository ini merupakan bagian dari inisiatif open-source di bawah naungan **[FTI Open Source Initiative (FOSI)](https://github.com/FTI-Open-Source-Intiative-FOSI)**.

---

## 📌 Fitur Utama

- **📊 Dashboard Interaktif**: Ringkasan aktivitas internal, metrik proker, jadwal rapat terdekat, dan status pengajuan keuangan.
- **📅 Kalender Terpadu**: Jadwal agenda kegiatan, rapat dinas/biro, dan timeline program kerja.
- **📋 Manajemen Program Kerja**: Pemantauan progres, PIC, status eksekusi, dan detail setiap program kerja dinas/biro.
- **📝 Rapat & Notulensi**: Penjadwalan rapat dinas, absensi kehadiran, dan pencatatan notulensi digital.
- **📷 Presensi Piket Harian**: Sistem pencatatan piket dan kehadiran pengurus dengan integrasi simulasi deteksi wajah (Face Recognition).
- **💰 Pengajuan Keuangan**: Alur pengajuan dana kegiatan, pelaporan realisasi anggaran, dan approval bendahara.
- **🔔 Notifikasi Real-time**: Pemberitahuan agenda penting, pengingat piket, dan update status pengajuan.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Utilities**: [date-fns](https://date-fns.org/)
- **Linting & Code Quality**: [Oxlint](https://oxc.rs/)

## 🚀 Cara Menjalankan Proyek

### 1. Prasyarat
- Pastikan [Node.js](https://nodejs.org/) (versi 18+ direkomendasikan) dan npm/pnpm/yarn sudah terinstal.

### 2. Instalasi Dependensi
```bash
npm install
```

### 3. Menjalankan Server Development
```bash
npm run dev
```
Buka browser di alamat `http://localhost:5173` (atau port yang tertera di terminal).

### 4. Build untuk Production
```bash
npm run build
```
